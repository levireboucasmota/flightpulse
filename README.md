
# ✈️ FlightPulse

### Brazilian Aviation Intelligence & Flight Delay Analytics

FlightPulse is a data engineering and analytics project focused on investigating flight delays, airline performance, airport efficiency, and delay propagation across the Brazilian aviation network.

## 🎯 Objectives

- Analyze airline operational performance.
- Identify airports and routes with recurring delays.
- Investigate temporal patterns of flight delays.
- Explore potential delay propagation across airport operations.
- Build a reproducible data pipeline and analytical data warehouse.

## 📅 Data Coverage

2022–2026

Source: Brazilian National Civil Aviation Agency (ANAC).

## 🛠️ Tech Stack

- Python
- Pandas & NumPy
- PostgreSQL & SQL
- Power BI
- Git & GitHub

## 🏗️ Architecture

Medallion Architecture:
- Bronze: Raw data ingestion
- Silver: Data cleaning and validation
- Gold: Analytical datasets
